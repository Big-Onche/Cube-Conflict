# Windows

To compile the game launcher, place the following x64 MinGW-w64 static libraries here:

* `libSDL2.a` ([SDL releases](https://github.com/libsdl-org/SDL/releases), `SDL2-devel-VERSION-mingw`)
* `libSDL2_image.a` ([SDL_image releases](https://github.com/libsdl-org/SDL_image/releases), `SDL2_image-devel-VERSION-mingw`)
* `libSDL2_ttf.a` ([SDL_ttf releases](https://github.com/libsdl-org/SDL_ttf/releases), `SDL2_ttf-devel-VERSION-mingw`)

# Windows (français)

Pour compiler le lanceur du jeu, placez les bibliothèques statiques MinGW-w64 x64 suivantes ici :

* `libSDL2.a` ([versions SDL](https://github.com/libsdl-org/SDL/releases), `SDL2-devel-VERSION-mingw`)
* `libSDL2_image.a` ([versions SDL_image](https://github.com/libsdl-org/SDL_image/releases), `SDL2_image-devel-VERSION-mingw`)
* `libSDL2_ttf.a` ([versions SDL_ttf](https://github.com/libsdl-org/SDL_ttf/releases), `SDL2_ttf-devel-VERSION-mingw`)
